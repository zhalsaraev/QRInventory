# QRInventory

Small android app for the batch QR-code scanning

Небольшое приложение для Андроид для пакетного сканирования QR-кодов

Основное предназначение - помощь в учете/инвентаризации оборудования.

В первую очередь предусмотрено сканирование QR-кодов с данными в формате "Инвентарный номер Tab Серийный номер", которые в интерфейсе разделяются на соответствующие столбцы.

Также может сканировать и произвольные QR-коды, а также наиболее распространенные одномерные штрих-коды.

Поддержка создания, открытия, переименования, удаления списков-ведомостей. Созданный список можно отправить через стандартное меню Андроид.

По длинному тапу на записи (считанном коде) можно добавлять комментарий, а также удалять саму запись. Записи с комментариями подсвечиваются.

Предусмотрено включение фонарика для считывания кодов в темных местах, а также зум камеры (pinch-zoom).
